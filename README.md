# Sistema Barbearia Século XXI

Sistema de gestão (WaaS) para a Barbearia Século XXI — landing page + painel administrativo.

## Stack

- Next.js 16 (Turbopack), React 19, Tailwind CSS 4, TypeScript
- Firebase (Firestore, Auth, Storage)

## Estrutura

- `/` — landing page
- `/admin/*` — painel administrativo (agenda, comandas, financeiro, cadastros, menu)

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
